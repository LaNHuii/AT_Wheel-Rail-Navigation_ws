# 人物跟随落地方案与当前实现边界

## 已确认任务规则

- 采摘者带路，机器人不按轨道清单自主选择下一条轨道。
- 目标距离为车体最前端到人体最近表面的水平距离 0.30 m。
- 人物静止或放置采摘物时，底盘平移和旋转均停止。
- 自由路面允许车头随人转向；丢失后停车 30 s，只有整车扫掠区安全时才原地搜索一圈。
- 轨道内仅允许纵向跟随；丢失、障碍或数据失效时原地等待，不横移、不旋转、不自动倒退。
- 视觉端负责身份关联。当前目标健康时不得因旁人更近而换人；明确丢失后才允许生成新的 `binding_id`。
- 自动进轨仍采用固定传感器前端：入口估计、前轮夹轨验证、释放推进、四轮终验。

## 算法选择与对照计划

| 环节 | 首个落地基线 | 对照算法 | 暂不采用及原因 |
|---|---|---|---|
| 人体检测 | 视觉组 YOLO 轻量模型 | 较大 YOLO 模型，比较漏检率和 IPC 峰值 | 只用颜色/轮廓，温室光照和遮挡下鲁棒性不足 |
| 身份跟踪 | ByteTrack | BoT-SORT + ReID，重点比较交叉、遮挡和换人 | 每帧选择最近人，会在多人场景频繁误切换 |
| 相对位置滤波 | EMA 基线 | Kalman，比较延迟、抖动和短时预测 | 长时间纯预测，目标丢失时存在追错人风险 |
| 自由路面跟随 | 当前限速 P 控制器（无障碍基线） | MPPI Omni 与 DWB A/B，用于动态目标和绕障 | 把全局轨道覆盖规划继续作为主任务，已不符合当前目标 |
| 点云安全 | 固定高度/走廊/扫掠区几何判定 | 地面分割 + 体素/聚类；Nav2 Collision Monitor | 删除全部低矮点，会把圆轨和低矮障碍一起误删 |
| 轨内控制 | 纵向 P + 死区 + 限速 | PID，实测比较稳态误差和超调 | Nav2 自由规划，可能产生横移/旋转导致脱轨 |
| 局部定位 | 轮式里程计 + 底盘 IMU EKF | FAST-LIO2，比较遮挡区漂移与 CPU 峰值 | 单独使用 MID-360S 内置 IMU，已因精度要求淘汰 |
| 入口估计 | 平行圆轨点云聚类/直线拟合 + 相机辅助 | RANSAC、区域生长和模型拟合 A/B | 仅靠夹轨判断入口位姿，夹轨只能做最终物理确认 |

目前的 P 控制器只用于无障碍、低速联调。自由路面实际绕障必须在
Nav2 局部代价地图与 MPPI Omni/DWB 对照完成后，才可获得运动权。

## 实车前必须补齐

1. 确定 RGB-D 相机型号、驱动、内外参与 `TrackedPerson` 生产节点。
2. 标定 MID-360S、相机、底盘 IMU 到 `base_link` 的外参并测量点云遮挡。
3. 实现轮速 + 主 IMU 局部里程计，保证绕障和一圈搜索有可验证位姿。
4. 完成自由路面 Nav2 滚动代价地图及 MPPI Omni/DWB A/B 测试。
5. 实现 `RailEntryEstimate` 生产节点和 `ExecuteRailTransition` ActionServer。
6. 联调真实 CAN-FD、转矩/电流反馈、夹轨阈值、硬过流和故障码。
7. 实现顶层行为树插件与轨道作业记录；轨道记录须允许人工确认采摘完成。
