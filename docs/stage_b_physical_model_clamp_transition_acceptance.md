# 阶段 4.4 验收：新版模型、夹轨闭环与自然进退轨

日期：2026-09-22

状态：**Gazebo 基线通过；允许进入阶段 4.5。实车参数尚未冻结。**

## 验收范围

本次验收覆盖新版 URDF 合入、自由路面舵轮回位、轨上支撑与行驶、
0～10° 夹轨闭环，以及水泥路与直径 50 mm 圆轨之间的自然进轨和退轨。
不包含 MID-360/相机感知、真实入口位姿估计、真实电机阈值标定和自主任务编排。

## 新版模型

- 各 Link 的质量、质心和惯性取自只读文件 `robot(1).zip`，总质量检查为 20 kg；
- 转向关节限制更新为约 ±165°，驱动关节保持连续旋转；
- 车架、转向座、轮胎和内侧轨道圆柱使用独立简化碰撞体；
- 轮胎碰撞半径为 93.5 mm，内侧圆柱碰撞半径为 75 mm；
- 轨道半径 25 mm、中心距 600 mm；轨道中心位于水泥面以上 25 mm；
- 轮胎与圆柱的轴向中心和宽度按四个 STL 分别提取，不用对称假设覆盖原模型。

## 舵轮回位与夹轨

- 自由路面速度命令结束或超时后，先等待 0.5 s，再以 0.5 rad/s 回零；
- 夹轨从 0° 向最多 10° 缓慢探测，方向顺序 FL、FR、RR、RL 为
  `[-1, +1, +1, -1]`；
- 四轮独立判断接触；某轮接触后立即锁存并保持当时角度；
- 已实现未接触超时、反馈缺失、硬过转矩、取消和释放处理；
- 未确认四轮接触时拒绝切换到轨内模式；
- 仿真接触在约 2° 触发，经过确认采样后停止在约 ±3°，均小于 10°；
- 释放后四轮回到近零角，接触锁存全部清除。

Gazebo 位置控制器的 effort 不能代表真实堵转转矩，因此仿真配置显式启用
虚拟接触事件。实车配置默认关闭该功能，必须使用电控回传的四轮转矩或等效
电流。配置中的 1/3 阈值仅用于接口与失败路径验证，不是实车标定值。

夹轨后的轨上运动回归结果：`vx=0.10 m/s` 持续 5 s，纵向位移
0.4711 m、横向位移 -2.2 mm、偏航变化 0.0097 rad；停止漂移 1.43 mm；
四轮胎离地间隙为 30.74～32.30 mm。

## 自然进轨与退轨

复用的策略接口以“相对入口纵向位置、横向误差、航向误差、支撑状态”为输入。
Gazebo 验证脚本暂用真值提供这些观测；后续 MID-360/双相机只需替换观测源，
不改变状态机。

- 进轨：`align -> controlled approach -> symmetric U-end crossing`；
- 退轨：`rail reverse -> symmetric U-end crossing -> ground departure`；
- 接触 U 形横管期间强制 `vy=0、wz=0`，避免单侧接触后继续横移或转向；
- 三次独立冷启动进退轨循环全部通过。

三次进轨纵向位移为 1.5087～1.5104 m，峰值横向误差不超过 8.4 mm，
峰值航向误差不超过 0.0222 rad，停止漂移不超过 0.98 mm。
三次退轨纵向位移为 1.3558～1.3691 m，峰值横向误差不超过 18.2 mm，
峰值航向误差不超过 0.0198 rad，停止漂移不超过 0.25 mm。

将进退轨逻辑抽取为独立策略模块后又执行了一次同实例回归：进轨纵向位移
1.4553 m、峰值横向误差 8.2 mm、峰值航向误差 0.0224 rad、停止漂移
0.96 mm；随后退轨纵向位移 1.2998 m、峰值横向误差 8.2 mm、峰值航向误差
0.0184 rad、停止漂移 0.27 mm，进退轨均通过。

## 阶段结论与保留项

Gazebo 中新版模型、回位、夹轨、轨上行驶、自然进轨和退轨已形成可重复基线，
阶段 4.4 通过。以下内容不得由本次仿真结果代替：

1. 电控侧电流/转矩硬限制、堵转、温升和通信失联保护；
2. 四个转向零点、符号、减速比和真实接触/过转矩阈值标定；
3. 实车轮胎与内侧圆柱有效滚动半径标定；
4. 用 MID-360/双相机替代 Gazebo 真值的入口观测与支撑状态判断；
5. 真实 U 形轨道端部尺寸和允许入口偏差的实车回归。
